# Job Radar

If the user wants Job Radar set up, read `skills/job-radar/SKILL.md` and follow `skills/job-radar/references/setup.md` phase by phase. Ask for the CV first. Create nothing before the user approves the plan.

If you are changing this repository: the rules live in `references/rulebook.md`, the step lists in the mode files, the data model in `references/schema.md`. Keep them consistent, bump `assets/release.json` and add a CHANGELOG entry.
